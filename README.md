# LemonChecklists
Lemon manuals checklists/htmls for procedures

**Open the guides: [atmoschazzgit.github.io/LemonChecklists](https://atmoschazzgit.github.io/LemonChecklists/)**

No guides yet.

Other files:

- `index.html`: the guide list GitHub Pages serves at the site root.
- `style-guide.json`: colors, type and components shared by every guide page.
- `tools/save-figures.py`: saves figures fetched with the Lemon MCP `get_image` tool into `guides/img/<guide-name>/`.
- `CLAUDE.md`: workflow rules and house style for building guides.

Based on [Hellreaver/Lemon-Checklists](https://github.com/Hellreaver/Lemon-Checklists).
